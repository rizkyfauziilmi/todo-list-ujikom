# Aplikasi To-Do List

## Deskripsi

Aplikasi sederhana berbasis react untuk mencatat tugas harian

## Fitur

- Tambah tugas
- Tandai Tugas Selesai
- Hapus Tugas

## Struktur Folder

- `src/App.tsx` — komponen utama todo list, berisi state dan logika
- `src/components/button.tsx` — komponen tombol
- `src/components/todo-header.tsx` — header dan tombol tambah
- `src/components/todo-row.tsx` — baris todo
- `src/components/todo-table.tsx` — tabel daftar todo
- `src/components/todo-modal.tsx` — modal tambah/edit todo
- `src/types/todo.type.ts` — tipe data Todo
- `src/index.css` — entry Tailwind CSS
- `src/main.tsx` — entry React

## Cara Menjalankan

1. install nodejs
2. jalankan proyek dengan `npm run dev`
