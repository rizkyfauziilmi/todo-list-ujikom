# Aplikasi To-Do List

## Deskripsi

Aplikasi sederhana berbasis react untuk mencatat tugas harian

## Fitur

- Tambah tugas
- Tandai Tugas Selesai
- Hapus Tugas

## Struktur Folder

- `app.tsx` komponen utama todo list

## Cara Menjalankan

1. install nodejs
2. jalankan proyek dengan `npm run dev`
